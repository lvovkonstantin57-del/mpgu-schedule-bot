# Расписание МПГУ в Telegram: как всё устроено и как запускать

## Из чего состоит

| Часть | Файлы | Где работает |
|---|---|---|
| Мини-приложение | `сайт/index.html` | GitHub Pages, репозиторий `tg-webapp` |
| Бот + сервер данных (API) | `bot.py`, `db.py`, `api.py`, `excel_io.py`, `requirements.txt`, `.env` | Ваш сервер `135.106.163.67` |
| HTTPS для сервера | ставится автоматически (Caddy) | Тот же сервер, адрес `https://135-106-163-67.sslip.io` |

**Как это работает:**
1. Администратор загружает в админ-панель **список студентов** (ФИО + группа) и **расписание** групп.
2. Студент пишет боту `/start` и своё ФИО. Бот находит его в списке и сам определяет группу. Тех, кого нет в списке, бот не регистрирует и сообщает о них администратору.
3. Мини-приложение показывает студенту расписание его группы. ФИО и группу студент изменить не может — их меняет только администратор.

Данные (студенты, расписание, настройки семестра) хранятся на сервере в файле `/opt/schedule-bot/data.db`. В репозиторий на GitHub они не попадают.

## Первый запуск

### 1. Сервер
На своём компьютере в терминале:
```bash
cd ~/Desktop/"claude code"/schedule-bot && ./deploy.sh root@135.106.163.67
```
Введите пароль от сервера (символы не отображаются). Скрипт сам:
- поставит бота и сервер данных как службу (запускаются после перезагрузки, перезапускаются при сбоях);
- поставит Caddy и получит сертификат для `https://135-106-163-67.sslip.io`;
- проверит, что всё отвечает.

В конце должно быть **«ГОТОВО: бот и админ-панель работают»** и строка с командой `/admin …`.

Если написано, что `https://…` не отвечает, — у хостинга закрыты порты **80 и 443**. Откройте их в панели хостинга (раздел «Сеть» / «Firewall» / «Брандмауэр») и снова выполните `./deploy.sh`.

### 2. Мини-приложение на GitHub
1. Откройте https://github.com/lvovkonstantin57-del/tg-webapp
2. **Add file → Upload files** → перетащите `сайт/index.html` → **Commit changes**. Файл должен лежать в корне репозитория.
3. Через 1–2 минуты новая версия появится у всех.

### 3. Стать администратором
Отправьте боту команду из файла `.env` (строка `ADMIN_CODE`):
```
/admin КОД
```
Код срабатывает один раз: после этого других администраторов так назначить нельзя. Бот ответит «Готово, вы администратор» и пришлёт кнопку админ-панели.

### 4. Загрузить данные
В приложении откройте вкладку **«Админ»**:
1. **Студенты → Шаблон в чат.** Бот пришлёт Excel-шаблон. Заполните столбцы «ФИО» и «Группа» и загрузите кнопкой **«Загрузить Excel»** (или просто отправьте файл боту).
2. **Расписание → Шаблон в чат**, заполните, загрузите так же.
3. **Семестр:** дата начала семестра и чётность первой недели. От них зависит, какая неделя сейчас — чётная или нечётная.

После этого студенты могут регистрироваться: `/start` → ФИО → кнопка «Открыть расписание».

## Админ-панель

**Расписание**
- Выбор группы, список пар по дням. Нажмите на пару, чтобы изменить или удалить её; «Добавить пару» — новая пара.
- Номер пары подставляет время по звонкам: 1) 08:30–10:00, 2) 10:10–11:40, 3) 11:50–13:20, 4) 13:50–15:20, 5) 15:30–17:00, 6) 17:10–18:40, 7) 18:50–20:20, 8) 20:30–22:00.
- **Загрузить Excel:** у каждой группы из файла расписание заменяется целиком, остальные группы не меняются.
- **Выгрузить в чат:** бот пришлёт текущее расписание всех групп в Excel — его можно поправить и загрузить обратно.

**Студенты**
- Поиск, добавление, изменение ФИО и группы, удаление.
- Зелёная точка — студент зарегистрирован в боте.
- **Сбросить привязку к Telegram** — если студент сменил аккаунт или зарегистрировался по ошибке: он сможет пройти регистрацию заново.
- **Загрузить Excel** добавляет новых студентов; тех, кто уже есть, не дублирует.

**Семестр** — дата начала и чётность первой недели.

Файлы Excel можно не загружать через приложение, а просто **отправить боту** в чат — результат тот же.

| Группа | День | Неделя | № пары | Начало | Конец | Предмет | Тип | Аудитория | Преподаватель |
|---|---|---|---|---|---|---|---|---|---|
| ИВТ-21-1 | понедельник | каждая | 1 | 08:30 | 10:00 | Математический анализ | лекция | 305 | Иванов И. И. |

- **День:** понедельник…воскресенье (можно «Пн», «Вт»…).
- **Неделя:** каждая / нечётная / чётная (можно «числитель» / «знаменатель»); пусто = каждая.
- Нужен либо **№ пары**, либо **Начало и Конец**.
- **Тип:** лекция, практика, лабораторная, экзамен, зачёт, другое.

Если в файле есть ошибки, ничего не загружается, а бот или приложение перечисляет строки с ошибками.

## Уведомления администратору
Бот пишет администратору, если:
- студента нет в списке («Студента нет в списке: …») — добавьте его во вкладке «Студенты»;
- кто-то пытается зарегистрироваться под уже занятым ФИО — если это тот же человек с нового аккаунта, сбросьте привязку;
- студенты пытаются регистрироваться, а список ещё пуст.

## Обновление
- **Бот или сервер:** замените файлы в `~/Desktop/claude code/schedule-bot` и выполните `./deploy.sh root@135.106.163.67`. Данные (`data.db`) сохраняются.
- **Приложение:** загрузите новый `сайт/index.html` на GitHub.

## Полезные команды на сервере
| Что сделать | Команда |
|---|---|
| Логи бота в реальном времени | `journalctl -u schedule-bot -f` |
| Перезапустить бота | `sudo systemctl restart schedule-bot` |
| Логи HTTPS (Caddy) | `journalctl -u caddy -n 50` |
| Резервная копия данных | `cp /opt/schedule-bot/data.db ~/data-$(date +%F).db` |

## Команды бота
| Команда | Что делает |
|---|---|
| `/start` | Регистрация или кнопка «Открыть расписание» |
| `/register` | Зарегистрироваться студентом (если вы администратор и ещё и студент) |
| `/admin КОД` | Стать администратором (один раз) |
| `/admin` | Кнопка админ-панели (для администратора) |
| `/id` | Показать свой Telegram ID |

## Настройки (`.env` на вашем компьютере)
| Строка | Что это |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `WEBAPP_URL` | Адрес приложения на GitHub Pages |
| `API_URL` | Адрес сервера с данными: `https://135-106-163-67.sslip.io` |
| `PROXY_URL` | Прокси для связи с Telegram: `socks5://ЛОГИН:ПАРОЛЬ@АДРЕС:ПОРТ` |
| `ADMIN_CODE` | Код для `/admin` |

После изменения `.env` выполните `./deploy.sh root@135.106.163.67`.

## Частые проблемы
| Что происходит | Что делать |
|---|---|
| Приложение пишет «Нет связи с сервером» | Сервер выключен или закрыты порты 80/443. Выполните `./deploy.sh` — он проверит HTTPS и подскажет. |
| «Сессия устарела» | Закройте приложение и откройте снова. |
| Студент пишет, что бот его не находит | Проверьте ФИО во вкладке «Студенты» (ищется полное совпадение, буквы «е» и «ё» не различаются). |
| «Этот студент уже зарегистрирован с другого аккаунта» | Если это тот же человек — «Сбросить привязку к Telegram» у студента. |
| Бот не отвечает | `journalctl -u schedule-bot -n 50` на сервере. Часто это прокси: проверьте `PROXY_URL`. |
| Ошибка `Conflict: terminated by other getUpdates request` | Бот запущен ещё где-то (например, на вашем компьютере). Оставьте только сервер. |
| `Permission denied` при `./deploy.sh` | Неверный пароль от сервера. |
